# AgriControl — 温室コントロールの実験ラボ

温室の様子を1つの画面で見て、窓・ファン・ポンプを動かせる仕組みです。

## 1. 何の役に立つか

- 今の**温度・土の乾き・タンクの水の残り**が、1つの画面に出ます。
- まず画面のスライダーで「暑い」「乾いている」状態を作り、どう動くかを**練習**できます。実機を触らずに試せるので、壊す心配がありません。
- 同じ画面から、**実際の基板につながった機器**を動かせます。窓を開ける、ファンを回す、水をやる。練習と本番で操作が変わりません。
- **安全の仕組み**が常に見張っていて、行きすぎた動作や矛盾した指示は止まります。
- 外出先からでも使えます。ルーターの設定(ポート開放)は要りません。
- 進捗ダッシュボードで、どこまで進んでいて何が残っているかが分かります。

公開サイト: [コントロールサイト](https://agricontrol.phyowaisoe.com/) / [進捗ダッシュボード](https://agricontrol.phyowaisoe.com/taskmanagement/)

## 2. 使っている技術

| 部分 | 中身 |
| --- | --- |
| `firmware/` | ESP32-C3M-TRY のファームウェア。PlatformIO / Arduino C++ |
| `backend/` | FastAPI(Python)+ paho-mqtt の中継サーバー |
| `logic/` | 判断エンジン、安全監視、故障シミュレーション(Python、ホストで実行可能) |
| `simulator/` | 練習用と実機操作をかねたコントロール画面(HTML/CSS/JS、日英切替) |
| `tests/` | `logic/` の単体・境界・競合・順序テスト |
| `docs/` / `data/` | 設計書、進捗モデル、作業手順 |

- 通信は **MQTT**(自前の Mosquitto ブローカー)。基板もサーバーも外向きの接続だけで済むため、家庭のルーターに穴を開けずに外から操作できます。
- 設計の原則として、**どの操作も中央の制御ループを通ります**。画面・センサー・機器・通信のどれも、そこを迂回できません。
- 基板の仕様は `ESP32-C3M-TRY-R1-20230701.pdf`、全体設計は `ESP32_Virtual_Control_Lab_Blueprint.pdf` が元になっています。

```sh
python3 -m unittest discover -s tests   # 制御ロジックのテスト
python3 -m pytest backend/tests/        # 中継サーバーのテスト
```
